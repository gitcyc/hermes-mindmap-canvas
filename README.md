# Hermes Mindmap Canvas

A real-time Web Canvas for Hermes Agent.

## Features

- FastAPI backend
- WebSocket realtime updates
- React Flow frontend
- JSON mindmap persistence
- Hermes Agent skill integration
- Docker deployment on Unraid

## Default deployment URL

http://192.168.0.6:9321

## Runtime data

Runtime data is stored outside the repository on Unraid:

/mnt/user/appdata/hermes-mindmap-canvas/data/mindmaps/

## Roadmap
